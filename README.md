# 🧔🏻‍♂️ AbbasAgha VPN Management Panel (پنل مدیریت وی‌پی‌ان عباس آقا)

پنل جامع، مدرن و حرفه‌ای مدیریت سرورهای VPN و تانلینگ با رابط کاربری فارسی و انگلیسی، ۴ تم اختصاصی (عباس آقا، زهرا جون، یخی، کوروش)، پشتیبانی از چند پروتکل و چند نود، تانل BackPack و ربات تلگرام فروش خودکار با درگاه‌های پرداخت متنوع.

## ✨ ویژگی‌های کلیدی
- **پشتیبانی از پروتکل‌های متنوع:** V2Ray / Xray (VLESS, VMess, Trojan, Reality)، WireGuard، OpenVPN و L2TP/IPsec
- **مانیتورینگ لحظه‌ای (Real-time):** نمایش زنده مصرف CPU، RAM، هارد، لوکیشن سرور و سرعت آپلود/دانلود لحظه‌ای کاربران آنلاین (مشابه پنل سنایی)
- **سیستم نود (Multi-Node):** اتصال نامحدود سرورهای خارج به سرور مرکزی برای توزیع بار و ارائه لوکیشن‌های مختلف
- **ماژول تانلینگ پیشرفته:** اجرای مستقیم تانل **BackPack**، Gost و IR-TNL از داخل رابط کاربری
- **مدیریت Outbound و Routing:** تعریف خروجی‌های اختصاصی (WARP، سرور دوم، مسدودسازی تبلیغات و سایت‌های ایرانی)
- **پنل نمایندگی (Reseller System):** ایجاد نماینده با محدودیت تعداد کاربر قابل ساخت، سقف حجم مصرفی و مدیریت مستقل
- **صفحه سابسکریپشن (Subscription Page):** صفحه وب ریسپانسیو و رنگی برای مشاهده حجم باقی‌مانده، تاریخ انقضا، QR Code و لینک اتصال یک‌کلیکی
- **۴ تم گرافیکی اختصاصی با لوگوهای وکتوری:**
  1. **عباس آقا (Abbas Agha):** مشکی و سبز نئونی با لوگوی داش مشتی
  2. **زهرا جون (Zahra Joon):** صورتی شیک و مدرن با لوگوی اختصاصی
  3. **یخی (Ice):** سفید برفی و آبی یخی (Glassmorphism)
  4. **کوروش (Cyrus):** طلایی، فیروزه‌ای و مشکی با المان‌های تخت جمشید
- **ربات تلگرام متصل به دیتابیس:** فروش خودکار، تست رایگان، تمدید و پشتیبانی از ۴ روش پرداخت (**کارت به کارت**، **زرین‌پال**، **آبان‌گیت** و **درگاه ارز دیجیتال**)

## 🚀 نصب سریع (تک‌دستوری) روی Ubuntu 20.04 / 22.04 / 24.04

پس از آپلود این مخزن در گیت‌هاب خود (مثلاً `YOUR_USERNAME/abbasagha-panel`)، با دستور زیر روی هر سروری نصب کنید:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/YOUR_USERNAME/abbasagha-panel/main/install.sh)
```
